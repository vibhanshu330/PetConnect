## Security update — 2026-10-09

Implemented a global session-bound CSRF filter for all POST requests. JSP forms now include the synchronizer token, multipart image forms validate it from their token part, and logout uses POST. Login and registration also require tokens. Added BCrypt (cost 12) password hashing with SHA-256 prehashing to avoid BCrypt's 72-byte input truncation. The former salted SHA-256 format remains accepted; a valid login upgrades that account's hash in place. If the upgrade write fails, the valid login still proceeds and migration is retried next time. The existing `password_hash VARCHAR(255)` column is sufficient. No SQL was run and no database records or schema were changed.
